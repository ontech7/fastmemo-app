## 📱 Mobile 4.1.0

- Refreshed editor: headings, quotes, checkboxes, code blocks, highlighter and Markdown.
  - A compact bar with menus: line styles (Normal, two headings, quote, code), lists (bullets, numbers, checkboxes), inserts and
    the rest.
  - Markdown works as you type it (`# `, `- `, `[] `, `**bold**`, `==highlight==`, `` `code` ``) and when you paste it: one undo
    gives the pasted text back as it was.
  - Web addresses become links as you type them; a link opens with the system, never inside the editor.
  - Notes written with the new kinds of line still open on Fast Memo 4.0.0.
- Links between notes: type [[ to link another note, and open it with a tap.
  - The picker searches your notes as you type; a link to a locked note still asks for the secret code.
- Reminders: a notification at the time you choose, from a note.
  - Quick choices (in an hour, tonight, tomorrow morning, Monday) or any date and time; the card shows the reminder.
  - Reminders are scheduled on the phone only: nothing goes through a server. With sync on, every phone that holds the note
    rings.
- One search: finds a word in every note and category, and opens the note right there.
  - It reads titles, text, list items, board cards and code, shows the line where the word is, and lists your `#tags`.
  - Accents don't matter, and the search runs on the phone, while the app is idle, so typing stays smooth.
- Widgets: a new note from the Home screen, or a note always in sight.
  - "New note" starts a note, a list or a dictation; the note widget shows the note you choose, and a tap opens it.
  - A protected or hidden note is never shown in a widget.
- History: go back to an earlier version of a note.
  - A version is kept before anything that isn't you typing rewrites a note: the AI, an agent, a sync, replace all, deleting
    completed items, a restore.
  - Versions stay on this device and never sync. An emptied note goes to the trash instead of disappearing.
- Share to Fast Memo: text, links and photos from other apps become a note.
- Drag to reorder: boards, lists and categories, smoother.
  - One drag for boards, lists and the categories' Organize page: the item follows your finger, the others make room, and each
    move is saved at once.
- Lists: Enter adds the next item, and completed items can be hidden or deleted.
- Code notes: find and replace.
- Photos and copies: take a photo right into a text note, or duplicate a note.
- Icon shortcuts: new note, new list and dictation.
- A faster app and various fixes.
  - A faster start: widgets and notifications load after the home has drawn.
  - Typing in a long list or a busy board redraws only the item you are typing in.
  - Drawings for empty screens, glass toasts, and a screen that reopens the app after a crash.
  - A note of a type this version doesn't know says so, instead of a blank screen.
  - Reports always carry the app version, the system and the language, and can include an email; device details are opt-out.
  - After an update, a short message tells you what's new.

## 🖥 Desktop 2.2.0

- Refreshed editor: headings, quotes, checkboxes, code blocks, highlighter and Markdown, and pictures pasted or dropped in.
  - The same editor as the phone, with its Markdown shortcuts and pasting.
  - Pictures pasted or dropped into a text note are resized like the phone's photos; a transparent picture keeps a white
    background instead of turning black.
- Links between notes: type [[ to link another note, and open it with a click.
- Reminders: set one from a note, and it rings on your phones.
  - The computer doesn't ring: with sync on, the phones that hold the note do.
- One search: finds a word in every note and category, and opens the note right there.
- History: go back to an earlier version of a note.
- Keyboard: arrow keys move through the notes, Enter opens one, Delete trashes it.
- Right-click and selection: a menu on notes, and selection with Ctrl/Cmd + click and Shift + click.
- Print and PDF: from the system's dialog, with real text instead of a picture.
  - A text note prints as text, so a PDF saved from the dialog can be searched and copied.
- Window zoom: Ctrl/Cmd + and −, remembered when you reopen it.
- Drag to reorder: boards, lists and categories, smoother.
- Lists: Enter adds the next item, and completed items can be hidden or deleted.
- Code notes: find and replace.
- Copies: duplicate a note from its menu.
- Various fixes and improvements.
  - Esc closes a note's find bar.
  - Reports say the system's version.
